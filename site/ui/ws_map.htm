学习率和梯度到底啥关系？我老是混。

11月8日 22:39

好问题。一句话：梯度告诉你往哪走，学习率告诉你走多远。

如果只看一个样本的更新，就是这条规则：

python
p = 0.5            # 当前的估计
eta = 0.2          # 学习率
for y in [1, 1, 0, 1]:
    p = p + eta * (y - p)
    print(round(p, 3))

建议去实验笔记把 eta 改成 0.9 再跑一遍——你会看到 p 在目标值两侧来回跳，那就是"过冲"。
