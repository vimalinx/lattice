# 一个数字怎样学习：让 p 一步步挪向目标 1
target = 1.0

for lr in (0.1, 0.5, 1.5, 2.5):
p = 0.0
trail = []
for step in range(8):
error = target - p
p += lr * error # 往目标挪一点，挪多少由学习率决定
trail.append(f"{p:6.2f}")
print(f"学习率 {lr:<4}", " ".join(trail))

把猜测 p 往目标挪一步：error 是还差多少，乘上学习率 lr 就是这一步挪的距离。

比如 lr=0.5、p=0 时差 1，这一步挪 0.5，p 变成 0.5。

lr 为什么大于 2 就停不下来？

11月8日 22:42

因为每一步的误差会乘上 1 - lr。lr 在 0 到 2 之间，|1 - lr| < 1，误差越来越小；大于 2 时 |1 - lr| > 1，每一步都比上一步跨得更远。

上面输出里 2.5 那一行就是这样：0、2.5、-1.25、4.38……越跳越远。
