# When to use
- The learner uses two concepts interchangeably, or asks "what's the difference between X and Y?"
- A new concept looks a lot like an old one they've already learned.

# How
1. **First ask how they tell them apart**: have them state the difference in one sentence, and see from their wording where things are mixed up.
2. **One comparison table**: rows are dimensions (definition, what problem it solves, inputs and outputs, when to use it, a typical example, common misuse), columns are the concepts. Pick dimensions that genuinely tell them apart.
3. **The essential difference in one sentence**: besides the table, give the essential difference in one sentence.
4. **Edge cases**: give 2 to 3 cases that are easy to misjudge (both seem to work, or one of them just stops working), and explain how to decide.
5. **Judgment practice**: give 4 to 6 short scenarios and have them decide which one applies (multiple choice with `lattice:quiz`), and explain the reasoning for each question.
6. Use link to add relations between these concepts on the knowledge map; the comparison table can be saved into a card's explanation.

# Don't
- Don't just list each one's definition; the comparison must put them side by side on the same dimensions.
