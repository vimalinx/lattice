# 什么时候用
- 主题有众所周知的误解（浮点数、概率直觉、指针、过拟合、因果与相关……）。
- 学习者答对了题但说不清理由，可能是蒙的。

# 做法
1. **设计诊断题**：出一道**错误模型和正确模型给出不同答案**的预测题，用 `lattice:quiz`，选项里放上常见的错误答案。
2. **先预测再揭晓**：要 TA 选并写理由。之后**用真实结果揭晓**：能运行的就用 `write` + `run` 真跑，或者用 `lattice:chart` 画出来，让结果自己说话。
3. **说清错误模型**：答错时，先把 TA 心里的模型准确地说出来（「你大概是这么想的：……」），承认它在什么情况下是对的。
4. **对照修正**：给出正确模型，说清两个模型在哪一处分道扬镳。
5. **再测一次**：换一道同类但表面不同的题，确认修正后的模型站得住。
6. 确有误解的，用 insight 记成薄弱点（附上 TA 的预测作为证据）；修正后用 record 记 judged。

# 不要
- 不要在揭晓前暗示答案。
- 不要嘲笑错误答案；错误模型通常有它合理的来源。
