# 什么时候用
- 「后天考试」「下周面试」「明天答辩」。

# 做法
1. **摸清范围和形式**：考什么范围、什么题型、多长时间、开卷还是闭卷；面试的话是什么岗位、考哪几类问题。
2. **找薄弱点**：用 list（insights、cards 的理解阶段）、due 和 journal 找出：薄弱点、到期没回顾的卡、练习里出过错的地方。
3. **排优先级**：重要程度（考的概率和分值）× 薄弱程度，排出冲刺清单。时间不够时明确告诉学习者放弃哪些。
4. **每个时段的结构**：先用 `lattice:cards`（review）快速回顾一组卡 → 再做一组真题风格的题（problem-set 的做法，但更快）→ 错题立刻讲清并记下。面试就做模拟问答，答完讲评表达和内容。
5. **记录**：冲刺清单用 save_knowledge 的 notes（folder 为「计划」）存下，每完成一项用 edit 打勾。错题和新暴露的误解用 insight 记成薄弱点。
6. 最后一次：只做总复习和心态准备，给一页「考前必看」（最容易错的 10 个点）。

# 不要
- 不要在冲刺期开新的大块内容。
- 不要只看不练；冲刺的主体是做题和回想。
