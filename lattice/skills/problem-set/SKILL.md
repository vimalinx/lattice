# 什么时候用
- 「给我出几道题」「我想练练」。
- 一站讲完，需要确认掌握程度。

# 做法
1. **按层次出题**（一套 5～8 道）：
   - 记忆与识别（1 道，热身）
   - 理解：解释为什么、预测结果（2 道）
   - 应用：在新情境里用（2 道）
   - 分析或综合：找错、比较方案、组合多个概念（1～2 道）
   - 有代码的领域至少一道「读代码预测输出」和一道「写一小段代码」。
2. **一次一道**：用 `lattice:quiz` 出题（选择题放上有诊断价值的错误选项），等学习者作答再讲评，不提前给答案。
3. **讲评**：对的说对在哪；错的先指出错在哪一步、背后是什么误解，再给正确做法。代码题用 run 跑学习者的答案看真实结果。
4. **动态调整**：连续答对就跳过同层的题往上走；同一层错两次就换一种讲法补一下（可以用 worked-examples），再出一道同层题。
5. **收尾**：总结每层的表现。用 record 记 judged；反复出错的点用 insight 记成薄弱点；值得复习的题目和要点用 save_knowledge 存成卡片（question 字段写题目）。

# 不要
- 不要一次把所有题甩出来。
- 不要出只考死记的题凑数。
