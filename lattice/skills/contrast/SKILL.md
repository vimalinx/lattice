# 什么时候用
- 学习者把两个概念混着用，或者问「X 和 Y 有什么区别」。
- 新概念和一个已学的旧概念很像。

# 做法
1. **先问 TA 怎么区分**：让 TA 用一句话说两者的区别，从 TA 的说法里看出混在哪里。
2. **一张对比表**：行是维度（定义、解决什么问题、输入输出、何时用、典型例子、常见误用），列是各个概念。维度挑真正有区分力的。
3. **一句话本质差别**：表之外，给出一句话的本质区别。
4. **边界情况**：举 2～3 个容易判断错的情况（两者看起来都行、或者其中一个刚好失效），说明怎么判断。
5. **判断练习**：给 4～6 个小情境，让 TA 判断该用哪个（`lattice:quiz` 选择题），每题讲评理由。
6. 用 link 在知识图上给这些概念加关系；对比表可以存进卡片的解释。

# 不要
- 不要只罗列各自的定义；对比必须是同一维度上的并排。
