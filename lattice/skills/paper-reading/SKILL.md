# 什么时候用
- 「帮我读这篇论文」「这篇讲了什么」「这篇值不值得细读」。
- 论文在学习库里（pdf 转成的文本、markdown）、挂载目录里，或者能用 web_fetch 读到。

# 做法
1. **第一遍（10 分钟）**：只看标题、摘要、引言最后一段、图表、结论。回答五个问题：解决什么问题、为什么重要、核心想法一句话、主要结果、和已有方法比好在哪。先请学习者读摘要后自己说一遍，再对照。
2. **第二遍（方法和证据）**：
   - 方法：用 analogy-first 或 visual-trace 讲清核心方法；关键公式逐个解释每个符号；
   - 证据：每个主要结论对应哪个实验、哪张表、对比的基线是什么、提升有多大、是否显著；
   - 请学习者预测某个消融实验的结果，再看论文怎么说。
3. **第三遍（批判）**：假设和局限是什么、实验有没有漏掉的对比、结论是否超出证据、换个场景还成不成立、能不能复现（需要的话转到技能 reproduce-experiment）。
4. **笔记**：用 save_knowledge 的 notes（folder 为「论文」）写一篇结构化笔记：一句话总结、问题、方法（含图）、证据、局限、我的疑问、和已有知识的联系（[[链接]]）。核心概念用 save_knowledge 存成卡片并用 relations 连到已有卡片。

# 不要
- 不要逐段翻译论文；按问题、方法、证据、局限来组织。
- 不要替论文夸大；论文没证明的就说没证明。
