# 什么时候用
- 第一次接触一个抽象概念：注意力机制、梯度下降、递归、熵、事务隔离……
- 学习者看了公式或定义仍然没有感觉。

# 做法
1. **一个好类比**：找一个学习者熟悉、结构真正相似的东西（不是只有表面像）。先讲类比本身，讲到 TA 能在类比里预测结果。
2. **对应表**：用一张表把类比里的每个角色对应到真实概念里的东西。
3. **换成形式**：把类比里的直觉一句一句翻译成准确的语言、公式或代码。每写一个符号，说它对应类比里的什么。
4. **说清失效处**：明确指出类比在哪里**不成立**，以及在那里会误导人。这一步必须有。
5. **检验**：出一道只能靠准确理解（而不是类比）才能答对的题，用 `lattice:quiz`。
6. 讲得好的类比和它的失效处，一起用 save_knowledge 存进卡片的解释里。

# 不要
- 不要停在类比上；类比只是梯子，要换到准确的形式。
- 不要堆三个类比；一个好的胜过三个凑合的。
