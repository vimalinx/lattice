# 什么时候用
- 「帮我整理一下学习库」「笔记太乱了」「有没有重复的卡片」。
- 定期维护（比如每月一次）。

# 做法
1. **体检**（只读）：
   - list 各类内容，graph 看关系；
   - 孤立的：没有任何链接、也不属于任何主题的笔记和卡片；
   - 重复的：标题相近、内容大部分重合的卡片或笔记（用 search 和 read 核对）；
   - 缺链接的：正文提到了某个已有卡片或笔记的标题，却没写 [[链接]]；
   - 过期的：计划、进度文件里早已过期没更新的；
   - 没归属的：明显属于某个主题却没挂上去的。
2. **整理方案** ⏸ 检查点：按类别列出发现的问题和建议的处理（合并哪两张、给哪篇加哪些链接、哪些挂到哪个主题、哪些建议学习者删），每条附依据。**先给学习者看，不直接动手。**
3. **动手**（学习者同意的部分）：
   - 加链接：edit 改正文，或 link 加关系；
   - 合并重复：把内容并到保留的那张（edit），另一张请学习者自己删（删除只归学习者）；
   - 归属：link 或 edit 改属性。
   每一类改动单独做，方便撤销。
4. **报告**：回复里一两句话说做了什么、还剩什么需要学习者自己决定。

# 不要
- 不要删除任何东西；删除只由学习者来做。
- 不要改「我的理解」和理解阶段。
- 不要未经同意大规模改写学习者的笔记。
