# 什么时候用
- 「把这些整理成卡片」「我想以后复习」。
- 一站讲完、学习者已经回应过，内容值得长期记住。

# 做法
1. **只提炼讲过的**：用 conversation 读对话，只用实际讨论过、学习者也回应过的内容。
2. **一张卡一个点**：每张卡只讲一件脱离对话也成立的事。标题是这个点的名字（名词短语，如「softmax 的数值稳定写法」），不是一个问题。
3. **好的解释**：body 用两三句话讲清这个点，加一个最小的例子；公式用 $…$。
4. **好的自测题**（question 字段）：要求预测、解释或判断，不是复述定义。
   - 差：「什么是过拟合？」
   - 好：「训练集准确率 99%、验证集 60%，模型最可能出了什么问题？你会先试哪两种办法？」
5. **连起来**：先用 list cards 和 search 看有没有同名或相近的卡（有就作为补充，不要重复建）；用 relations 给新卡和已有卡加关系（prerequisite、part_of、related、contrasts…）。
6. 用 save_knowledge 一次存完；回复里列出存了哪几张，用 `lattice:cards` 展示出来。

# 不要
- 不要一张卡塞一整节内容。
- 不要替学习者写「我的理解」；那一块只归 TA。
- 不要把没讲过的内容做成卡。
