# 什么时候用
- 刚开始一个主题，不知道学习者的底子。
- 学习者说「基础我应该都会」或「我完全不会」，但没有证据。

# 做法
1. **先看证据**：graph、list cards、journal 里已有的理解阶段和作答记录先看一遍，已经有证据的部分不再考。
2. **出 4～8 道诊断题**：按主干从浅到深，每题对应路线上的一站，考的是「能不能用」，不是「知不知道名字」。一次只出一道（`lattice:quiz`），按回答决定下一道：
   - 答对且理由对 → 跳到更深的一站。
   - 答错或理由不对 → 在这一站附近再问一道确认。
3. **允许「不知道」**：明确告诉学习者不会就选「不知道」，蒙对没有意义。
4. **给出定位**：总结 TA 在每一站的状态（已掌握 / 不牢 / 没学），说明依据是哪道题。建议从哪一站开始讲。
5. 用 record 记一条 judged（诊断结论和依据）；暴露出的误解用 insight 记成薄弱点。然后直接从建议的那一站开始讲。

# 不要
- 不要出成考试；题少而准，十分钟以内。
- 不要因为一道题答错就判定整站不会；再确认一次。
