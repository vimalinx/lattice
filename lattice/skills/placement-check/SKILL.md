# 做法
1. **先看证据**：「关于学习者」里记下的、graph、卡片的理解阶段、轨迹里的作答，已经有证据的部分不再问。
2. **出一份问卷**（`lattice:survey`，4～8 题，一次出完）：
   - 一半问背景和目标：学来做什么、想做到什么程度、相关的经验（学音乐会问会不会某种乐器、能不能看谱；学编程会问写过什么）。用选项，少用简答。
   - 一半是小题，按路线由浅入深，每题对应一站，考「能不能用」而不是「知不知道名字」，选项里都放「不知道」。
   - intro 用一句话说为什么问：好从合适的地方开始讲。这一轮到问卷为止。
3. **定位**：问卷回来后，一两句话说清判断（已经会 / 不牢 / 没学到哪一站）和依据是哪几题；用 route 把已经会的站标 done、起点标 now，不牢的地方用 insight 记下，换个主题也成立的背景用 remember 记下。
4. 然后直接从起点开讲。

# 不要
- 出成考试；两分钟能填完。
- 一道题答错就判整站不会：拿不准的那一站，开讲时先用一道 `lattice:quiz` 确认。
- 学习者跳过了问卷还追问。
