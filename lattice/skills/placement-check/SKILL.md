# 做法
1. **先看证据**：graph、卡片的理解阶段、轨迹里的作答，已经有证据的部分不再考。
2. **一题一题问**：每题对应路线上的一站，考「能不能用」而不是「知不知道名字」，用 `lattice:quiz`，选项里放一个「不知道」。答对且理由对就跳深一站，答错或说不清就在这一站附近再确认一道。一般 3～6 题。
3. **定位**：一段话说清每站的状态（已经会 / 不牢 / 没学）和依据是哪道题；用 route 把已经会的站标 done、起点标 now，不牢的地方用 insight 记下。
4. 然后直接从起点开讲。

# 不要
- 出成考试；十分钟以内。
- 一道题答错就判整站不会。
