# 什么时候用
- 「我一个月内要学会 X」「下周面试」「每天只有一小时」。
- 已经有了教程树或主题路线，需要排时间。

# 做法
1. **确认约束**：截止时间、每周可用时间、哪些天不能学、最终要达到的程度（能用 / 能讲 / 能考）。
2. **估工作量**：从主题路线（read 主题）出发，给每站估一个时间（讲解 + 练习 + 复习），复杂的站多给。总量超过可用时间时，**先砍分支，再把某些站降为「了解」**，并告诉学习者砍了什么。
3. **排周计划**：每周 = 1～3 站 + 一次练习（start_practice）+ 一次回顾（due 的卡片）。每周留 20% 缓冲。考前或上线前最后一段留给综合复习。
4. **写下来**：用 save_knowledge 的 notes（folder 为「计划」）写一篇「<主题> 学习计划」，每周一节：目标、要学的站、检验方式、完成后打勾的待办（`- [ ]`）。用 update_topic 在主题档案里写上计划的位置和当前进度。
5. **跟进**：之后每次学习开始时，读计划和 journal，告诉学习者「这周到哪了、落后多少」；落后就重排，不要硬塞。

# 不要
- 不要排满；没有缓冲的计划一周就会作废。
- 不要只排「看」，每周都要有能检验掌握的产出。
