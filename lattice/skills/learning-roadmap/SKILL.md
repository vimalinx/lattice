# 做法
1. **约束**：截止时间、每周能用多少时间、要达到什么程度（能用 / 能讲 / 能考）。学习者没说的按常见情况估，并在计划里写明是估的。
2. **估量**：从主题路线出发（read 主题，没有路线先按「教程树」排一条），给每站估时间（讲解 + 练习 + 回顾）。总量超出时先砍按兴趣的方向，再把某些站降为「了解」，告诉学习者砍了什么。
3. **排周**：每周 1～3 站、一次动手练习、一次卡片回顾，留两成缓冲；期限前最后一段留给综合复习。
4. **写下**：save_knowledge 的 notes（folder 为「计划」）写「<主题> 学习计划」，每周一节：目标、要学的站、怎么检验、`- [ ]` 待办。主题档案里记一句计划在哪、现在到第几周。
5. **跟进**：之后每次开讲先对照计划和轨迹，一句话说这周到哪了；落后就重排，不硬塞。

# 不要
- 排满没有缓冲。
- 只排「看」：每周都要有能检验的产出。
