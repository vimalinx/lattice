# 做法
1. **起点**：学习者说了自己的水平就按它排；没说就从最稳妥的起点排，讲第一站时顺带确认。不先盘问。
2. **主干**：从起点到目标 6～12 站，按「不懂前一站，后一站就学不下去」排序。每站是一两轮能讲完、能检验的一块：title 写这站讲什么，why 写学完能做到的一件可检验的事（能算出……、能解释……、能写出……）。
3. **对照已有**：graph 里已有的卡片和课程，对得上的站用 ref 指过去；有证据已经会的站标 done。
4. **存下**：没有主题就 create_topic（question 写这个领域要回答的核心问题，route 写主干），有主题就用 route 整条替换；要讲的第一站标 now。按兴趣再选的方向在主题档案里列一行，等学习者真往那边走再开分支。
5. **给学习者看**：照附带的 tree-template.md 列出路线：每站写「你会看到」的那个具体例子、「学完你来做」的一件事和「怎么算过关」，标出最短闭环和现在在哪；学习者没说的（节奏之类）空着，不为它发问。同一轮接着把第一站讲起来。
6. **之后**：讲完一站就挪 now；发现缺前置用 replan 补站。路线随学习调整，不用等学习者确认才开讲。

# 不要
- 列书单和网址代替路线。
- 站太粗（「学会深度学习」）或太碎（「知道 ReLU 这个词」）。
- 没有证据就把站标成 done。
