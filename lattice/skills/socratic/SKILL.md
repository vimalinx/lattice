# 什么时候用
- 学习者已经有相关基础，结论可以靠推理得出。
- 学习者问「为什么」，而直接告诉 TA 会让 TA 错过自己想通的机会。
- 练习里 TA 卡住了，但离答案只差一两步。

# 做法
1. **定终点**：先在心里写下这轮要 TA 自己得出的结论（一句话），以及从 TA 现在的认识到结论要过的 2～5 个台阶。
2. **一次只问一个问题**：每个问题只推进一个台阶，问 TA 能回答的东西（预测、举例、比较、找反例），用 `lattice:quiz` 让 TA 先作答。
3. **跟着回答调整**：
   - 答对：肯定是哪一点对了，再问下一个台阶。
   - 答错：不说「错」，问一个能让矛盾暴露的问题（「那这个例子里会怎样？」）。
   - 连续两次卡住：缩小问题，或者给一个具体的情境让 TA 算一算。
4. **让 TA 说出结论**：最后请 TA 自己把结论说完整，你再补上它的名字和适用范围。
5. 用 record 记一条 judged：TA 是自己走到的，还是在哪一步需要了提示。

# 不要
- 不要用反问句变相给答案（「难道不是 X 吗？」）。
- 不要连着抛三个问题；一次一个。
- 学习者明确说想直接要答案时，就给答案，再用一个问题检验 TA 懂了没有。
