# 什么时候用
- 「我想做一个 X 来学 Y」「学了理论想练手」。
- 一个主题学到一半，需要把几站知识串起来用。

# 做法
1. **定项目**：和学习者一起选一个能在 3～8 次学习里完成的项目，写清：做完是什么样（能演示的结果）、用到主干上的哪几站、不做什么（范围边界）。
2. **拆里程碑**（3～6 个）：每个里程碑 = 一个能运行、能看到效果的中间结果 + 它需要的知识点。先做最小可运行版本，再一个个加功能。
3. **每个里程碑这样走**：
   - 先讲（或复习）这个里程碑需要的知识点；
   - 用 start_practice 开一个练习（lesson 写清这一步要用的讲解要点，goal 写这个里程碑的验收标准），让练习教练带 TA 做；
   - 练习结束后复盘（练习复盘流程），确认验收标准达到了再进下一个。
4. **记下来**：用 save_knowledge 的 notes（folder 为「项目」）写一篇项目说明：目标、里程碑列表（`- [ ]`）、每个里程碑的验收标准和用到的知识点。每完成一个就用 edit 打勾，写一句做到了什么。
5. **收尾**：项目完成后，请学习者讲一遍整个项目的结构和最难的一步；把项目中学到的、能脱离项目成立的知识存成卡片。

# 不要
- 不要选一个三个月才做得完的项目。
- 不要替学习者写项目代码；骨架可以给，关键部分 TA 自己写。
