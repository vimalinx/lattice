# 什么时候用
- 「X 领域现在都有哪些方法」「A、B、C 选哪个」「帮我调研一下 X」。

# 做法
1. **定问题** ⏸ 检查点：调研要回答的问题、用途（学习、选型、写报告）、时间范围、深度。
2. **检索**：web_search 多换几种关键词（中英文、同义词、「survey」「benchmark」「vs」）；对关键来源用 web_fetch 读原文。学习库里已有的用 search 和 read。每条记下：出处、时间、要点、可信度（论文 / 官方文档 / 博客 / 论坛）。
3. **分类**：把方法或方案按核心思路分成几类（3～6 类），每类说清代表作、核心思想、适用场景。画一张分类图（mermaid mindmap 或 flowchart）。
4. **对比**：一张对比表，维度按调研目的选（效果、成本、成熟度、生态、学习曲线……），每个格子都要有依据。
5. **结论**：按用途给出建议，并说明在什么条件下建议会变。不确定的地方明说。
6. **存档**：用 save_knowledge 的 notes（folder 为「调研」）写调研综述（带全部出处链接）；值得深入的方向，按技能 tutorial-tree 建成主题或分支。

# 不要
- 不要只靠一个来源；重要结论至少两个独立来源。
- 不要把搜索结果的摘要直接当结论；读原文。
- 过时的信息要标出时间。
