# Lattice

本地桌面上的学习工作台。界面里只有两个使用者：你和 AI。AI 给你看的东西都在它自己的面板里；你深度处理的东西（笔记、代码、实验笔记、数据）都在你的面板里。所有学习数据都是一个文件夹里的普通文件。设计见 `docs/DESIGN.md`。

## 启动

```bash
cd ~/Projects/Lattice
python3 run.py
```

依赖：Python 3.11+、PySide6（含 QtWebEngine）、jupyter_client、ipykernel、httpx、PyYAML、numpy、matplotlib；运行代码和 AI 沙箱另需 `uv` 与 `bubblewrap`。编译型语言按需安装（gcc、rustc、go、node……），缺什么，运行时会直接说缺什么、怎么装。

## 界面

- 最左边是固定的活动栏，旁边是左栏。左栏按用途分区：主题、知识卡、笔记、课程、实验与代码、练习与薄弱点、全部文件、搜索，每个分区有自己的列表；再点一次当前分区的图标（或 Ctrl+B）收起左栏。属于某个分区的入口放在那个分区的顶上：知识图在「主题」，回顾在「知识卡」，命令面板（Ctrl+K）在「搜索」。活动栏底部只剩学习轨迹、开始页、明暗和设置；最下面一条状态栏显示当前主题、谁在工作、沙箱状态。
- 中间是面板：默认左边是「主会话」，下面单独一块是「快答」，右边是「开始」页，文件打开在右边。所有面板都能拖动标签换位置：拖到另一组标签上并排成标签页，拖到某块区域的边缘就分栏；标签上的按钮可以浮出成悬浮窗，拖动分隔条调整大小。布局自动保存，也可以在设置里存成有名字的布局、设为默认。
- 活动栏的「＋」：写记录、写代码（任何语言）、新实验笔记、新知识卡，以及打开主会话、快答和各个面板。Ctrl+K 搜索文档、文件、以往对话和命令。
- 对话面板：AI 的回复是一栏限宽的正文，你的话在右侧气泡里；时间、复制、开始练习、存成卡片在鼠标移上去时出现。AI 做了哪些事折叠成一行，点开能查看或撤销。往上翻时右下角有「↓」回到最新。输入框一行时是胶囊，多行时变成圆角矩形；左边的「＋」附上文件，右边可以只给这个窗口换模型。还没开始聊时，输入框在中间，下面是接着学某个主题、回顾到期的卡、回到练习之类的起点。
- 大小：设置里调全局的字号、行距、阅读宽度和每种窗口的默认比例；某一个窗口可以单独调（鼠标放在上面 Ctrl + 滚轮，或者 Ctrl + = / Ctrl + - / Ctrl + 0，标签上右键也行），会跟布局一起存下。
- AI 也能控制整个界面：开关、摆放、浮出面板，换一种布局，切换左栏，改外观。它每次动手都在回复下显示一行，点「还原界面」就回到它动手之前的样子。

## 和 AI 学

- 平时就在主会话那里想到什么说什么，不需要先建主题。值得长期深入的内容，主会话会自己建成主题或某条主线的分支，写下主干路线，把相关的对话一起带过去；它岔开、接回主干都会记进轨迹。
- 每个 AI 都能读你的知识图、学习轨迹和你此刻的界面（开着什么、看到哪一节、选中了什么、有没有没保存的草稿），由它自己判断你在哪、该学什么、什么时候提议回到主干。发消息时附一行界面附注。
- AI 的回复里可能有展示块：让你先预测或作答的题（答案记进轨迹）、一组知识卡（回顾模式下由你自评）、知识图或某个主题的路线图、图表、轨迹片段、某个文件的一段摘录。代码块可以直接运行看结果，或者「拿到我这边」存成你的文件。
- AI 对你文件的修改，除了整理你刚写完的东西和你明确让它改的时候，都以「修改建议」出现在它的回复下面，你点了才应用。它做的每一步都在回复下显示为一行，可以查看或撤销。
- 选中任何地方的文字或代码，会出现「问快答 / 问主会话」。
- 主会话某条回复下点「开始练习」，或者主会话自己判断该动手时，会开一个练习：练习教练在 AI 那边一步步带你写，练习文件（.py、.ipynb、.c、.rs……按内容选）在你这边。结束练习后主会话读完整记录复盘，记下薄弱点和接下来的讲解重点。
- 「写记录」「写代码」开的是随手写的文件；关掉以后整理助手在后台给它起标题、理结构、连到相关的卡片和笔记，原文留在历史里，整理的每一步都能撤销。设置里可以关掉。

## 你的文件

- 一个工作台打开所有文件：Markdown 笔记和课程（编辑 / 分屏 / 预览，可以切到「原文」直接改属性），知识卡（解释、自测题、「我的理解」、理解阶段、回顾自评、关系、来自轨迹的证据），主题（问题、主干路线、主题档案、里面的内容、分支、练习、薄弱点），实验笔记（单元格、内核、输出），代码（编辑、运行、输出），CSV 表格，图片。
- 打字停下就自动保存。文件在别处被改了而你这边还有没保存的修改时，会让你选载入新版本还是保留自己的。每个文件都有历史版本，可以对照、恢复。
- 理解阶段、「我的理解」、回顾自评和删除只归你；AI 读得到、改不了。

## 运行与环境

- 任何文件都能运行：.py、.js、.ts、.c、.cpp、.rs、.go、.sh、.rb、.lua、.jl、.R、.java……运行器表在设置里可以加行或改写。运行时工作目录是文件所在的目录，输出实时显示，matplotlib 的图直接出现在输出里；可以随时停止，有时限。
- Python 用学习库自己的环境，由 uv 管理：定义写在 `envs/<名字>.txt`，环境在 `.lattice/venvs/` 里，第一次用时自动建好（默认带 ipykernel、numpy、matplotlib）。运行时缺包会自动装上、写进定义、再跑一次；装了什么记进轨迹，可以撤销（撤销后环境跟着定义回退）。设置里可以关掉自动装，这时运行结果里会给一个「装上再运行」的按钮。某个目录里放一个内容是环境名的 `.lattice-env` 文件，这个目录下的文件就用那个环境。挂载的外部目录有自己的 `.venv` 就用它的。
- 你点的运行用你自己的权限。AI 发起的运行和命令都在沙箱里（bubblewrap）：学习库可写，挂载的目录只读，家目录的其余部分和各种凭据看不到，不联网；对话、轨迹、规则和环境对沙箱只读。
- 实验笔记的内核默认也在沙箱里，你和 AI 共用同一个内核；需要联网或读你自己的文件时，可以在实验笔记顶上把内核切到「我的权限」，这时 AI 不能在里面运行。

## 学习库：所有数据都是文件

默认在 `~/Lattice/`（可用环境变量 `LATTICE_VAULT` 指定），本身是一个 git 仓库：

```
AGENTS.md                         所有 AI 每轮都读的规矩，你可以直接改
topics/ cards/ lessons/ notes/ insights/   Markdown，属性在开头的 YAML 里
notebooks/                        标准 .ipynb
code/ data/                       任意代码和数据，原样保存
envs/<名字>.txt                    Python 环境的定义
agents/<名字>.md                   可选：放一份就能改写那个 AI 的工作方式
threads/                          对话（JSON lines，只追加）
journal/<年>/<日期>.jsonl          学习轨迹（只追加）
.lattice/                         索引、环境、运行输出、本机状态，都可以重建
```

- 引用一律用文件开头的 `id`；文件名和文件夹只是给人看的。可以用任何编辑器直接改，Lattice 每两秒检查一次，外面新放进来的 Markdown 第一次被读到时写上 `id`。
- 你的编辑停顿约 30 秒、或任何 AI 动作之前自动提交；AI 的每个动作单独提交一次，作者写明是哪个 AI。撤销把那次提交改过的文件逐个改回去，之后又被改过的不会被覆盖。轨迹和对话只追加，不参与撤销。
- 第一次在没有学习库的机器上启动时，会把旧数据库 `~/.local/share/lattice/lattice.db` 迁移成文件；旧数据库只读，原样保留。
- 设置里可以导出整个学习库（ZIP，不含索引、本机状态和凭据）、导入一个 Markdown 笔记目录（只复制）、挂载本地目录（你能读写，AI 只读）。

## 模型和联网

- 四个 AI（主会话、快答、练习教练、整理）各自选 API 连接和模型，都走 OpenAI 兼容的 Chat Completions（流式 + 工具调用）。内置 DeepSeek、CommandCode、OpenCode Go 和一个自定义连接，每个连接各存一份 Key。
- 联网有两个接口：搜索和读网页，什么时候查由 AI 判断，来源列在回复下面并记进轨迹。搜索服务在设置里选：DuckDuckGo（不需要 Key）、自建 SearXNG、Brave、Tavily。读网页不会访问本机和局域网地址。
- 设置能改所有东西：外观与交互、布局与左栏、四个 AI 的模型和规则（工具、历史条数、规则全文，改了存进学习库的 `agents/`）、模型连接、联网、运行器和 Python 环境、沙箱、学习库的位置和挂载目录、学习库的规矩（AGENTS.md）。
- 本机配置在 `~/.config/lattice/providers.json`（权限 0600），界面偏好和存过的布局也在里面。界面只知道有没有 Key，拿不到 Key 本身；Key 也可以用环境变量 `DEEPSEEK_API_KEY`、`COMMANDCODE_API_KEY`、`OPENCODE_GO_API_KEY` 提供。日志和浏览器配置在 `~/.local/share/lattice/`。使用模型时，相关的学习内容会发给你配置的模型服务。
