Lattice 的第一个版本：一个和 AI 一起学东西的本地学习工作台。你和 AI 在同一个界面里学，它讲解、画图、出题、陪你做实验，你写笔记、跑代码、做卡片；所有学习数据都是你电脑上一个文件夹里的普通文件，用 git 记着每一步。

## 安装

- **Windows**：下载 `Lattice-0.1.0-setup.exe` 安装（装在用户目录下，不需要管理员权限），或者下载 `Lattice-0.1.0-windows-x64.zip` 解压后运行 `Lattice.exe`。安装包自带 git 和 uv，不用另外装 Python。安装包没有代码签名，第一次运行时 SmartScreen 会拦一下：点「更多信息」→「仍要运行」。
- **Linux**：从源码运行，见 [README 的快速开始](https://github.com/vimalinx/lattice#快速开始)。需要 Python 3.11+；AI 的沙箱要 `bubblewrap`，运行代码要 `uv`。

装好后在设置的「模型连接」里选一家服务、贴上 API Key，就可以开始了。

## 这个版本能做什么

- **主会话和快答**：主会话负责讲，想学什么直接说，值得深入的它会建成主题、排出主干路线，发现你哪块不熟就在路线上补几站。快答回答旁枝末节的小问题，不打断主讲；它不属于哪个主题，界面上开着的标签（笔记、代码、实验、网页、应用……）它都能按需去读。
- **开始学之前先摸底**：主会话不清楚你的底子时，先出一份两分钟的问卷，据此决定从哪讲起。
- **回复里能动手**：关系图、能拖参数的小实验、小题、图表；代码块一点就运行。
- **应用**：要一个能动手操作或可视化的小程序时，应用助手在后台做成一个 HTML 应用，做好了自动打开；改应用是在原文件上改，版本留在历史里能对比。
- **笔记、实验和知识卡**：像 Obsidian 的笔记（双链、公式、表格、有序列表接着编号），带补全的代码编辑器，Jupyter 实验笔记；讲过的东西整理成知识卡，按理解阶段和到期时间回顾。
- **导入 ChatGPT 的对话接着聊**：贴上分享链接就能导入，回答里的交互小部件也能用。
- **界面随你摆**：工作区、分栏、浮出，标签可以拿到单独的大窗口（再放回原处）；文件按「主题 → 会话」组织。
- **技能**：27 个讲解和做事的方法（费曼讲解、苏格拉底追问、论文精读……），可装、可改；AI 提议的修改你在左右对照里审。
- **模型随便接**：二十多家预设服务加本机 Ollama 等，也能完全自定义。

## 已知问题

- Windows 版没有沙箱：AI 的命令和运行用你的权限直接执行（状态栏显示「直接运行」），学习库里的改动照样一步一步记进历史、可以撤销。
- Linux 沙箱联网偶尔会卡住一次请求（大约几次里有一次），重试即可。
- 导入目前只支持 ChatGPT 的分享链接。
- Linux 还没有打包好的安装方式。

有问题或建议欢迎在 [Issues](https://github.com/vimalinx/lattice/issues) 里说。
