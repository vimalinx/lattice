这个版本让单独的窗口真正能用来干活：在里面开标签、分栏，标签能在窗口之间直接拖，一样东西只开在一个窗口里。

## 安装

- **Windows**：下载 `Lattice-0.3.1-setup.exe` 安装，或者下载 `Lattice-0.3.1-windows-x64.zip` 解压后运行 `Lattice.exe`。安装包没有代码签名，第一次运行时 SmartScreen 会拦一下：点「更多信息」→「仍要运行」。
- **Linux**：下载 `Lattice-0.3.1-linux-x64.tar.gz`，解压后运行里面的 `Lattice`。不用装 Python 和 Qt，但系统里要有 `git`；AI 运行代码和沙箱还需要 [`uv`](https://github.com/astral-sh/uv) 和 `bubblewrap`。需要 glibc 2.39 或更新的发行版。也可以从源码运行，见 [README 的快速开始](https://github.com/vimalinx/lattice#快速开始)。
- **macOS（Apple Silicon 预览版）**：下载 `Lattice-0.3.1-macos-arm64-preview.dmg`，注意事项见 [macOS 预览版](https://github.com/vimalinx/lattice#macos-预览版)。

## 单独的窗口能开标签了

面板放大成单独的窗口后（悬浮窗标签上的按钮，或者右键标签），那个窗口不再只能放一个面板：

- **标签栏和主窗口的一样。** 每个标签能浮出、关闭，末尾的「＋」能再开别的东西放进这个窗口，拖标签就能分栏。
- **在里面打开的东西留在里面。** 从「＋」打开的、在里面点的链接、在里面问的 AI 打开的，都开在这个窗口里，不再跑到主窗口去。
- **标签能直接拖到另一个窗口里。** 主窗口和单独的窗口之间都能拖；拖过去之前，没保存的修改先写好。
- **最后一个标签关掉，窗口也就关了。**

## 一样东西只开在一个窗口里

一个文件已经开在单独的窗口里，在主窗口再点它，会把那个窗口提到前面显示它，而不是在主窗口再开一份；反过来也一样，AI 要打开它时也照这个来。以前同一个文件可能在两个窗口里各开一份，两边都能改，后保存的会盖掉先保存的。

## 放回主窗口

- **按钮都在标签栏右上角。** 单独的面板窗口和放着工作状态的窗口，「放回主窗口」都在同一个地方；工作状态窗口底栏左下角的 ↩ 去掉了，那里只留它的名字。
- **回到拿出来时的那个工作状态。** 以前放回时会落进主窗口当时显示的那个工作状态。现在回到原来那个：拿出来的面板回到原来的位置（原来是悬浮窗就还是悬浮窗），后来在窗口里开的放到它这一类平常打开的地方；那时主窗口在别的工作状态，就不切过去，只在底栏那个工作状态上亮个点。
- 窗口里怎么摆的一直记着；Lattice 关闭时还开着的单独窗口，下次启动时里面的面板都这样回到主窗口。

## 已知问题

- 在窗口之间拖标签，目前只在 Linux 的 Wayland 下实际试过；在一个 X11 的测试环境里拖不过去，Windows 和 macOS 还没试过。拖不过去时，可以先点「放回主窗口」。
- Windows 和 macOS 版没有沙箱：AI 的命令和运行用你的权限直接执行（状态栏显示「直接运行」）。macOS 上默认关闭 AI 运行代码和命令。
- Linux 沙箱联网偶尔会卡住一次请求，重试即可。
- Linux 打包版目前只在 Ubuntu 24.04 上自动验证过能启动，别的发行版还没试过。
- 导入目前只支持 ChatGPT 的分享链接。
- 有 DRM 的书打不开；扫描版 PDF 没有文字层，你能看，AI 读不出字。
