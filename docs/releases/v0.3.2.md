这个版本接着把单独的窗口补完整：主会话、快答、大纲与链接、设置这些开在单独窗口里时，在主窗口做的操作也会交到它们那里去做。

## 安装

- **Windows**：下载 `Lattice-0.3.2-setup.exe` 安装，或者下载 `Lattice-0.3.2-windows-x64.zip` 解压后运行 `Lattice.exe`。安装包没有代码签名，第一次运行时 SmartScreen 会拦一下：点「更多信息」→「仍要运行」。
- **Linux**：下载 `Lattice-0.3.2-linux-x64.tar.gz`，解压后运行里面的 `Lattice`。不用装 Python 和 Qt，但系统里要有 `git`；AI 运行代码和沙箱还需要 [`uv`](https://github.com/astral-sh/uv) 和 `bubblewrap`。需要 glibc 2.39 或更新的发行版。也可以从源码运行，见 [README 的快速开始](https://github.com/vimalinx/lattice#快速开始)。
- **macOS（Apple Silicon 预览版）**：下载 `Lattice-0.3.2-macos-arm64-preview.dmg`，注意事项见 [macOS 预览版](https://github.com/vimalinx/lattice#macos-预览版)。

## 交给另一个窗口里的面板

0.3.1 起一样东西只开在一个窗口里。但很多操作不只是打开一个面板，还要对它做点什么；面板开在别的窗口里时，以前只会把那个窗口提到前面，要做的事就丢了。现在要做的事跟着一起过去，由开着它的窗口来做：

- **选中文字「问快答 / 问主会话」**，以及应用里选中的文字：引用放进那个窗口里对话的输入框，光标也在那里。
- **快答「转交给主会话」、把对快答说的内容交给主会话深入、答主会话出的小题**：消息在那个窗口里的对话里发出去。
- **Ctrl + J**：焦点落到那个窗口里快答的输入框。
- **回到标记或批注的地方**：那个窗口里的对话或网页滚到标记处，标出的字闪一下。
- **点笔记里的 #标签**：那个窗口里的「大纲与链接」切到标签页，展开这个标签。
- **打开设置的某一页**（比如笔记 ⋯ 菜单里的「笔记默认的显示方式…」）：那个窗口里的设置翻到这一页。
- 试用技能、再打开回顾、技能修改的对照窗口，也都照这个来。

## 主题在窗口之间同步

一个工作状态的主会话开在单独的窗口里，在主窗口换主题、开新会话、归档或删除会话，那个窗口里的对话会跟着换过去；反过来在那个窗口里换主题，主窗口里这个工作状态也跟着换。

## 修复

- 对话已经开着时，回到里面的标记只闪了一下，没有滚过去（停在原来的位置）。现在会滚到标记处。

## 已知问题

- 在窗口之间拖标签，目前只在 Linux 的 Wayland 下实际试过；在一个 X11 的测试环境里拖不过去，Windows 和 macOS 还没试过。拖不过去时，可以先点「放回主窗口」。
- Windows 和 macOS 版没有沙箱：AI 的命令和运行用你的权限直接执行（状态栏显示「直接运行」）。macOS 上默认关闭 AI 运行代码和命令。
- Linux 沙箱联网偶尔会卡住一次请求，重试即可。
- Linux 打包版目前只在 Ubuntu 24.04 上自动验证过能启动，别的发行版还没试过。
- 导入目前只支持 ChatGPT 的分享链接。
- 有 DRM 的书打不开；扫描版 PDF 没有文字层，你能看，AI 读不出字。

有问题或建议欢迎在 [Issues](https://github.com/vimalinx/lattice/issues) 里说。
