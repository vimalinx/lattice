修好了一个 AI 权限开关不完整的问题，并新增 Apple Silicon 的 macOS 预览版。

## 修复

- **「允许 AI 运行代码和命令」现在对命令也生效。** 以前这个开关只拦运行文件，拦不住 AI 的命令行：关掉之后，它还能执行命令。现在两者都听这个开关。在 Windows 和 Linux 上默认仍是打开的；如果你关掉过，AI 的命令从这个版本起才真正停下，有的回答可能因此要你自己运行一步。
- **AI 对运行环境的了解更准确**：工具说明按平台来写，只有确实有沙箱时才说在沙箱里。

## macOS 预览版（Apple Silicon）

- 下载 `Lattice-0.2.1-macos-arm64-preview.dmg`，把 Lattice.app 拖到「应用程序」。需要 macOS 13 或更新；Intel Mac 不支持。
- 需要 Git：第一次使用前在终端运行 `xcode-select --install`。第一次运行学习库里的代码时要联网下载 Python 和需要的包。
- **这是预览版**：没有 Apple Developer ID 签名和公证，macOS 可能阻止打开。确认来源后，可以在「系统设置 → 隐私与安全性」里允许；系统不给这个选项时，只能等签名版。
- **macOS 上没有沙箱，所以 AI 运行代码和命令默认关闭。** 打开后，AI 的命令用你的权限运行，碰得到学习库以外的文件，也能联网。
- 按住 Option 拖动窗口是复制（在 Mac 上 Ctrl 加点击等于右键）。切换工作状态用 ⌘⇧1～9。
- 由 GitHub Actions 从这个版本的源码构建，`SHA256SUMS.txt` 是校验值。
- 还没验证过：干净的 Mac、macOS 13、MPS 训练。

最初的 macOS 适配由项目的一位朋友完成，感谢。

## 安装

- **Windows**：下载 `Lattice-0.2.1-setup.exe` 安装，或者下载 `Lattice-0.2.1-windows-x64.zip` 解压后运行 `Lattice.exe`。
- **Linux**：从源码运行，见 [README 的快速开始](https://github.com/vimalinx/lattice#快速开始)。

有问题或建议欢迎在 [Issues](https://github.com/vimalinx/lattice/issues) 里说。
