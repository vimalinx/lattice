这个版本起 Lattice 能自己更新：每天到 GitHub 看一次有没有新版本，下载和安装都等你点。笔记也有新东西：每篇笔记自动带上写下它那天的日期标签，模板里的日期可以写格式和偏移。

## 安装

- **Windows**：下载 `Lattice-0.3.3-setup.exe` 安装，或者下载 `Lattice-0.3.3-windows-x64.zip` 解压后运行 `Lattice.exe`。安装包没有代码签名，第一次运行时 SmartScreen 会拦一下：点「更多信息」→「仍要运行」。
- **Linux**：下载 `Lattice-0.3.3-linux-x64.tar.gz`，解压后运行里面的 `Lattice`。不用装 Python 和 Qt，但系统里要有 `git`；AI 运行代码和沙箱还需要 [`uv`](https://github.com/astral-sh/uv) 和 `bubblewrap`。需要 glibc 2.39 或更新的发行版。也可以从源码运行，见 [README 的快速开始](https://github.com/vimalinx/lattice#快速开始)。
- **macOS（Apple Silicon 预览版）**：下载 `Lattice-0.3.3-macos-arm64-preview.dmg`，注意事项见 [macOS 预览版](https://github.com/vimalinx/lattice#macos-预览版)。

0.3.2 和更早的版本里还没有更新功能，这一次要像以前一样手动下载安装。装上 0.3.3 以后，再有新版本就能在 Lattice 里直接更新。

## 自动更新

设置里多了一页「更新」：

- **检查**：Lattice 启动后，如果离上次检查已经超过一天，就到 GitHub 看一次有没有新版本，之后每天一次。只读取发布页上的版本号和说明，不发送你的任何数据。这一页上可以关掉自动检查，也可以随时点「检查更新」。
- **提示**：发现新版本时只提示一次，设置的「更新」那一项上会留一个小圆点；这一页上能看到新版本的说明。
- **下载**：点「下载更新」，显示进度，可以取消。下载的文件会对照发布页给出的大小和 SHA-256 校验，对不上就不用。
- **安装**：下载好后点「重启并更新」。Lattice 先保存各个窗口里正在写的内容，然后关闭，换上新版本：
  - **Windows 安装版**：静默运行新的安装程序，装好后自动打开 Lattice。
  - **Windows zip 版、Linux 版**：新版本先解开在程序文件夹旁边，Lattice 关闭后替换旧的文件夹，再打开新的 Lattice。替换失败时把旧文件夹放回去。
  - **macOS**：打开下载好的安装盘，退出 Lattice 后把里面的 Lattice 拖进「应用程序」替换旧的。
  - **从源码运行**：只提示用 `git pull` 更新。

学习库和设置都不受影响。GitHub 的接口每小时只回答同一个网络地址 60 次，共用出口的网络（校园网、代理）可能被拒；这时 Lattice 改从 GitHub 网站本身读取版本号、说明和安装包，只是拿不到 SHA-256，只核对大小。

## 笔记的日期标签

- **新笔记**：标签里自动带上写下它的那天，比如 `2026-11-07`（`notes/模板/` 里的模板除外）。在「大纲与链接」的标签里点这个日期，就列出同一天写的笔记。
- **已有的笔记**：升级后第一次打开学习库时，按各自的创建日期补上日期标签，不改它们的修改时间。这一步单独记一次版本，可以撤回。
- **不想要**：直接删掉这个标签，删了不会再加回来。
- **标签栏**：点进标题下面的标签栏，会列出今天的日期和已经在用的标签，常用的在前。点一下就加上，接着打字可以筛选。

## 模板里的日期和时间

- **格式**：`{{date}}`、`{{time}}`、`{{title}}` 在用模板时填上，可以写格式，比如 `{{date:YYYY年M月D日 dddd}}` 填成「2026年11月7日 星期六」。可用的有年月日、时分秒、上午下午、星期、月份名、季度和 ISO 周，`[方括号]` 里的字原样保留。
- **偏移**：`{{date-1d}}` 是昨天，`{{date+1w}}` 是下周的今天。单位有 y、M、w、d、h、m，其中 M 是月，m 是分钟。
- **插入模板**：笔记右上角的 ⋯ 菜单里可以把模板插到光标处。
- **输入 `{{`**：正文里输入 `{{` 会补全出此刻的日期、时间、星期、昨天、明天、第几周和标题，选中后直接填进去。在模板里则填进标签本身，等用模板时再换。

## 修复

- 有的笔记改名或移动后，版本历史里看不到改名之前的版本。现在能看到了。

## 已知问题

- 自动更新在 Linux 上实际试过完整的下载、替换和重新打开；Windows 和 macOS 上还没实际试过，要等到下一个版本发布时才第一次真正用上。如果更新没装上，到发布页手动下载安装就行，学习库不受影响。
- 在窗口之间拖标签，目前只在 Linux 的 Wayland 下实际试过；在一个 X11 的测试环境里拖不过去，Windows 和 macOS 还没试过。拖不过去时，可以先点「放回主窗口」。
- Windows 和 macOS 版没有沙箱：AI 的命令和运行用你的权限直接执行（状态栏显示「直接运行」）。macOS 上默认关闭 AI 运行代码和命令。
- Linux 沙箱联网偶尔会卡住一次请求，重试即可。
- Linux 打包版目前只在 Ubuntu 24.04 上自动验证过能启动，别的发行版还没试过。
- 导入目前只支持 ChatGPT 的分享链接。
- 有 DRM 的书打不开；扫描版 PDF 没有文字层，你能看，AI 读不出字。

有问题或建议欢迎在 [Issues](https://github.com/vimalinx/lattice/issues) 里说。
