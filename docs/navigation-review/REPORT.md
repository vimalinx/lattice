## 导航动画补充验收（2026-10-14）

导航宽度与内容边界使用 240ms CSS 过渡；文字折叠时先淡出，展开时延后 65ms 淡入；图标只横向平移，不改变纵向位置。导航节点在切页与内容刷新时保持挂载，避免打断过渡或丢失键盘焦点。快速反向点击由 CSS 从当前进度连续反转，不排队、不锁按钮。尊重系统减少动态效果设置。

实际 Qt WebEngine 逐帧检查通过：普通模式 14 项、强制 prefers-reduced-motion 模式 13 项；包括中间宽度/透明度、内容边界跟随、图标纵坐标、连续七次反向点击、输入框 DOM/草稿不变、焦点保留、动画中刷新与切页。普通模式帧宽度实测从 208px 经 132px、82.8px、69.5px 连续收敛至 64px。结果在 motion.json 和 motion-reduced.json。
